# طعم ایران — دانشنامه دیجیتال آشپزی ایرانی

وب‌سایتی کاملاً فارسی و راست‌به‌چپ که غذاهای سنتی ایران را به همراه تاریخ، فرهنگ، مواد اولیه و خاستگاه جغرافیایی آن‌ها معرفی می‌کند.

## امکانات

- معرفی کامل بیش از ۲۰ غذای سنتی ایرانی با تاریخچه، مواد اولیه و نکات خواندنی
- نقشه تعاملی ایران برای کاوش غذاها بر اساس استان
- جست‌وجو و فیلتر بر اساس نام، مواد اولیه، استان و دسته‌بندی
- حالت روشن/تاریک، انیمیشن‌های نرم و طراحی گلاسمورفیک
- ریسپانسیو کامل برای موبایل، تبلت و دسکتاپ
- بهینه برای SEO (sitemap، robots، متادیتای کامل)

## اجرای پروژه

```bash
npm install
npm run dev
```

سپس آدرس [http://localhost:3000](http://localhost:3000) را در مرورگر باز کنید.

## ساخت نسخه نهایی

```bash
npm run build
npm run start
```

## ساختار پروژه

- `src/data` — داده‌های غذاها و استان‌ها
- `src/components` — کامپوننت‌های قابل استفاده مجدد (هدر، فوتر، کارت غذا، نقشه و...)
- `src/app` — صفحات اپلیکیشن (خانه، دانشنامه غذاها، صفحه جزئیات هر غذا)
