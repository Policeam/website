# 🍲 دانشنامهٔ خوراک ایرانی — Iranian Cuisine Encyclopedia

وب‌سایتی مدرن، واکنش‌گرا و کاملاً فارسی (راست‌چین) که به‌عنوان دانشنامهٔ دیجیتالِ
آشپزی ایران طراحی شده است؛ معرفی غذاهای سنتی ایران به‌همراه تاریخچه، مواد اولیه،
خاستگاه و اهمیت فرهنگی.

A modern, fully responsive, Persian (RTL) website designed as the digital
encyclopedia of Iranian cuisine.

## ✨ ویژگی‌ها

- **طراحی کاملاً فارسی و راست‌چین (RTL)** با فونت وزیرمتن.
- **حالت روشن و تاریک** با ذخیرهٔ ترجیح کاربر.
- **صفحهٔ اصلی چشم‌نواز** شامل بخش معرفی، غذاهای منتخب و دسته‌بندی‌ها.
- **نقشهٔ تعاملی ایران** برای کاوش غذاها بر اساس استان.
- **جستجو و فیلتر** بر اساس استان، دسته‌بندی و مواد اولیه.
- **پنجرهٔ جزئیات** برای هر غذا با نام، تصویر، توضیح، مواد اصلی، خاستگاه،
  پیشینهٔ تاریخی، اهمیت فرهنگی و نکات جالب.
- **افکت‌های گلاس‌مورفیسم، گرادیان، انیمیشن‌های نرم و میکرو-اینتراکشن.**
- **واکنش‌گرایی کامل** برای موبایل، تبلت و دسکتاپ.
- **بهینه‌سازی برای موتورهای جستجو (SEO)** شامل متادیتا، Open Graph،
  داده‌های ساختاریافته (JSON-LD)، `robots.txt` و `sitemap.xml`.
- **بدون نیاز به مرحلهٔ ساخت (build)** — صرفاً HTML/CSS/JS خالص و سریع.

## 🗂 ساختار پروژه

```
.
├── index.html              # صفحهٔ اصلی و تمام بخش‌ها
├── assets/
│   ├── css/style.css       # شیوه‌نامه، تم‌ها و انیمیشن‌ها
│   └── js/
│       ├── data.js         # دادگانِ غذاها، استان‌ها و دسته‌بندی‌ها
│       └── app.js          # منطق جستجو، فیلتر، نقشه و پنجرهٔ جزئیات
├── robots.txt
├── sitemap.xml
└── README.md
```

## 🚀 اجرا

این پروژه ایستا (static) است و به هیچ وابستگی یا مرحلهٔ ساختی نیاز ندارد.
کافی است `index.html` را در مرورگر باز کنید، یا یک سرور سادهٔ محلی اجرا کنید:

```bash
# با پایتون
python3 -m http.server 8000

# یا با Node
npx serve .
```

سپس به نشانی `http://localhost:8000` بروید.

## ➕ افزودن غذای جدید

کافی است یک شیء جدید به آرایهٔ `DISHES` در فایل `assets/js/data.js` اضافه کنید.
هر غذا شامل این فیلدهاست: `name`, `type`, `province`, `city`, `image`,
`description`, `ingredients`, `history`, `culture`, `facts`.

> تصاویر از Unsplash بارگذاری می‌شوند؛ برای استفادهٔ آفلاین می‌توانید تصاویر را
> به‌صورت محلی در `assets/img/` قرار داده و مسیر `image` را به‌روزرسانی کنید.
